Get Started

Welcome to Simli

The API devs use to add faces to realtime AI agents

The Simli speech-to-video API lets developers create lip-synced AI avatar interactions. With visual AI avatars, you can create anything! Mock interviews, sales assistants, language learning, coaching, customer-service training, historical characters, and so much more. Ready to make your first one?

Use LiveKit Agents

Give a LiveKit Agents voice agent a Simli avatar that joins its LiveKit room.

Use Pipecat

Pipecat is an open-source Python framework for voice and multimodal agents. Add a Simli avatar to its pipeline.

Use Simli SDKs

For when you need full control of your tech stack (e.g., custom voice agents).

Choose your pathway

Each pathway needs a Simli API key, from your Simli dashboard. This is everything else you bring yourself:
PathwayRunsWhat you bring
LiveKit AgentsA Python agent in your LiveKit roomYour own LiveKit server, reachable from the internet: LiveKit Cloud, or self-hosted with a public address (not localhost). A key for your model provider: OpenAI for the starter.
PipecatA Python agent on your machineAn OpenAI API key. No other accounts.
JavaScript SDKIn the browserA backend route that creates session tokens, so your API key never goes in the browser.
Python SDKIn your Python programNothing else.
Raw WebRTCIn your own clientYour own WebRTC client.
