How do the avatar models compare on the same pipeline?
In this separate study, 60 people held 1,200 rated conversations with the same speech-to-text model, language model and text-to-speech model across providers. Only the avatar provider changed.
The shared pipeline used Deepgram Nova-3 as the speech-to-text model, Groq-hosted GPT OSS 120B as the language model and Cartesia Sonic-3.6 as the text-to-speech model.
Synthesia is included here because it uses a customer-supplied speech-and-language pipeline. This is a like-for-like comparison of that setup. The full-pipeline and LiveKit studies are reported separately because their configurations differ.

Methodology:
How response latency and connection time were measured
The main benchmark used 60 participants and 960 rated conversations, with each provider running its full pipeline. Anam used Cara-4.1 Express; competitors ran their defaults. The separate LiveKit study used 60 participants and 1,200 rated conversations on a shared speech-and-language pipeline.
Response latency
Time from the user finishing speaking to the avatar starting its reply. Measured from the two audio channels of each browser-captured recording, using the same method for every provider.
Connection time
Time from pressing Start to the first visible avatar video frame, also called time to first frame (TTFF). Measured from client connection events, including the provider’s session-creation API call.
Median and percentiles
The median is the middle measured time. P90, P95 and P99 describe the slower end of the results: 90%, 95% and 99% of measurements fall at or below those times.

Measured on October 16, 2026. These results describe the configurations tested on that date. Products and performance can change.
Data and transparency
The
benchmark repository
includes the methodology, evaluation code, de-identified ratings, session telemetry and provider configurations, so you can inspect the setup and reproduce the results.
Anam conducted this benchmark, and we recognise the conflict of interest in comparing our own product with competitors. The figures above use the study report’s published precision. Full-pipeline and LiveKit results are presented separately so each comparison reflects the configuration tested.
