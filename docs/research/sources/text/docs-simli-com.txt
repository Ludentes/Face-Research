The Simli speech-to-video API lets developers create lip-synced AI avatar interactions. With visual AI avatars, you can create anything! Mock interviews, sales assistants, language learning, coaching, customer-service training, historical characters, and so much more.
Ready to make your first one?

Use LiveKit Agents
Give a LiveKit Agents voice agent a Simli avatar that joins its LiveKit room.
Use Pipecat
Pipecat is an open-source Python framework for voice and multimodal agents. Add a Simli avatar to its pipeline.

Use Simli SDKs
For when you need full control of your tech stack (e.g., custom voice agents).
